the void

Most consultancies sell roadmaps. None ship a Stop button.

McKinsey shipped Turo, a portfolio tracker for AI initiatives that have already been funded. EY launched .ai Value Blueprints, an enterprise framework delivered through engagement. Accenture sells reinvention readiness across four maturity tiers.

PwC, Workday, Gartner, Microsoft Copilot, all in the same business. Every major firm in 2026 is selling build-side AI product. Killing an AI project, in their hands, is treated as an exception you escalate to, not a starting position.

What is missing is the framework that defaults to Stop, where the workflow has to survive an elimination test before any AI build dollar gets approved. The Workflow Coroner is that framework, callable on GitHub.

how it works

One orchestrator, five agents.

The Coroner is the runner that wires the pipeline end to end. Each agent has one input contract and one output contract, same engine runs deterministic Python or as Claude sub-agents, swappable per stage.

orchestrator
Coroner
The runner. Loads the fixtures, dispatches each workflow through the five agents in order, persists the artefacts, renders the verdict card and the 90-day plan. Mode switch on env vars decides whether Verdict runs deterministic Python or a real Claude sub-agent.
pulse
Pulse
Parses the event log, classifies the workflow by pace layer (Jeroen Tas), infers ai tier and readiness from rework, exception, and automation-coverage signals.
verdict
Verdict
Derives BVF pillar scores, calls the aibvf engine directly, returns Stop, Fix, Accelerate, or Keep. Ships deterministic, or as a real Claude sub-agent with senior-practitioner rationale attached.
architect
Architect
Branches on the ruling. On Stop drafts an elimination plan and a Prosci-grade CM treatment, on Fix proposes pillar raises, on Accelerate designs an agentic deployment in shadow mode.
wire
Wire
Mocks MuleSoft Anypoint, generates DELETE, PATCH, or POST calls per ruling, writes a JSON decommission log and a markdown change-management plan, holds a 30-day rollback transaction in escrow.
sequencer
Sequencer
Takes a portfolio of rulings and returns a 90-day rollout plan with named gates. Wave 1, days 1 to 30, all Stops, frees budget. Wave 2, days 31 to 60, quick Accelerates, banks early wins. Wave 3, days 61 to 90, complex Accelerates plus Fixes, resolves dependencies after the first two waves build trust.
