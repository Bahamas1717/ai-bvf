Executive KPI tile — serif value over an uppercase label, optional sub note.

```jsx
<KpiCard label="Net value at stake" value="€37.8M" sub="Across 6 initiatives" tone="accent" />
<KpiCard label="Portfolio verdict" value="Fix" tone="fix" />
```

`tone` recolours the value: `accent` · `accelerate` · `fix` · `stop` · `neutral`.
