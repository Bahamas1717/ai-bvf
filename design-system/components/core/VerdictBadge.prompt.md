RAG verdict chip — the framework's Accelerate / Fix / Stop signal with a glowing dot.

```jsx
<VerdictBadge verdict="Accelerate" />
<VerdictBadge verdict="Stop" size="lg" />
```

`verdict`: `Accelerate` (green) · `Fix` (amber) · `Stop` (red). `size`: `sm` · `md` · `lg`. Use `lg` for a standalone score readout, `sm` inline in tables.
