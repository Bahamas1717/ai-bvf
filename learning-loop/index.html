The Compounding Firm

A firm's lasting AI advantage is not the model it picks. It is the learning loop it owns, where human capital and token capital compound. This page shows that loop running, end to end, on the AI Business Value Framework. Offline reference run, 5 seeds.

The Veteran Test PASS

One owned artifact, fit on one base model, lifts a different model it was never fit on. The veteran lives in the file, not the model.

The moat PASS

One fixed artifact across a capability ladder. The firm advantage stays positive and does not collapse as base models get stronger.

Better generalists ride on top of the owned layer rather than erasing it.

How to reproduce

Everything runs with no API key. From learning-loop/:

python -m loop.run_loop · python -m sovereignty.swap_demo · python -m sovereignty.moat_demo

The charts above are regenerated into artifacts/ on each run. Honest caveat: this is a mechanism proof on sample data, not an ROI figure.

Provenance: the thesis (human capital and token capital compounding in a firm-owned learning loop, and a frontier ecosystem rather than just a frontier model) is Satya Nadella's. The contribution here is the operational layer that makes it testable: the Veteran Capital artifact and its spec, the runnable loop, and the Veteran Test and moat proofs. His thesis, the proof built here.
